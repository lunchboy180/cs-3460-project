## Build instructions
`vcpkg`, `ninja`, and their dependencies need to be installed to build!  

Linux:  
Run the `build.sh` script  

Windows:  
Run the `build.bat` script  

## Run instructions
Run the binary under `build/Slitherer`

Windows:  
Run the executable in `build-vcpkg/Release`
